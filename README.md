# ACADLINK_WEBSITE

The marketing website for AcadLink, a school management system for Philippine schools.

- Open `index.html` in a browser, or host this folder on any static host (GitHub Pages, Netlify, cPanel).
- Light and dark mode, scroll animations, and an inquiry form that emails acadlink20206@gmail.com through FormSubmit.
- Contact: 0977 698 0253

The first inquiry sent makes FormSubmit email an activation link; click it once so later inquiries arrive.
